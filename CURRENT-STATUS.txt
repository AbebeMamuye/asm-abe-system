  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Problem: Electron download keeps failing/timing out
───────────────────────────────────────────────────────────────────────────
Solutions:
1. Check internet connection speed (need ~5 Mbps+)
2. Clear cache:
   rmdir /s /q "%LOCALAPPDATA%\electron"
   rmdir /s /q "%LOCALAPPDATA%\electron-builder"
3. Try during off-peak hours
4. Use mobile hotspot if office internet is slow
5. Download manually from: 
   https://github.com/electron/electron/releases/download/v39.8.10/electron-v39.8.10-win32-x64.zip


Problem: "zip: not a valid zip file" error
───────────────────────────────────────────────────────────────────────────
Cause: Download was corrupted or incomplete
Solution: 
1. Clear cache (see above)
2. Try again with better connection


Problem: Next.js build fails
───────────────────────────────────────────────────────────────────────────
Solution: Skip it! The Electron app will build Next.js on first run
The installer works fine without pre-building Next.js


Problem: Can't login with new credentials
───────────────────────────────────────────────────────────────────────────
Solution:
cd default-app
npx prisma migrate deploy
npx prisma db seed
