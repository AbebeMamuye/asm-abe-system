📞 TROUBLESHOOTING

Issue: Build fails with "downloading Electron" timeout
Fix: Check internet, clear cache, try again
     rmdir /s /q "%LOCALAPPDATA%\electron"

Issue: Database errors
Fix: Reset database
     cd default-app
     npx prisma migrate reset --force

Issue: Can't login with new credentials
Fix: Ensure database was seeded
     cd default-app
     npx prisma db seed
